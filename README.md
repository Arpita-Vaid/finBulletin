## Project Overview

FinBulletin is a full-stack financial news platform that provides stock market news, portfolio tracking, and sentiment analysis. Users can explore financial news, create a sample portfolio, and analyze market sentiment through an intuitive interface.

## Features

* Financial news aggregation
* Portfolio management
* Sentiment analysis
* RESTful API integration
* Responsive user interface
* Real-time news fetching
* Error handling and loading states
